# アルトコイン機会分析

[简体中文](README.md) · [English](README.en.md) · 日本語 · [한국어](README.ko.md) · [Español](README.es.md)

アルトコインの急変動、資金調達率とベーシス、オンチェーン価格差、LPヘッジの履歴を調べるWindowsデスクトップツールです。急変動レーダーはRAVE、BSB、EVAA、LABを監視し、通知後3日・7日・14日の結果を追跡します。公開データの読み取り専用で、アカウントや取引用APIキーは不要です。

## インストールと起動

ソースをダウンロードし、Tcl/Tk付きのPython 3.12をインストールしてください。プロジェクトのディレクトリでPowerShellを開き、次を実行します。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m klinebot.alt_monitor_app
```

初期設定後は `start-monitor.bat` をダブルクリックしても起動できます。言語メニューで日本語を選ぶと、設定が保存されます。「監視を開始」で定期スキャン、「今すぐスキャン」で単発スキャンを実行します。ウィンドウを閉じると停止します。

## 取引機会の分析

- **資金調達率・ベーシス**。OKXのETH・SOL・LINK現物とリニア無期限契約を比較します。同じ数量、実際の決済間隔、往復手数料で損益を推計し、最初の正の推計を決済後の板と確定レートで検証します。
- **オンチェーン価格差**。EthereumのUniswap v3とOKXのUSDC現物でETH・LINKを双方向に比較します。両方の在庫を前提に、手数料と概算ガス代を差し引きます。正の価格差の期間は連続する有効な観測から求めます。
- **LPヘッジ検証**。Uniswap v3 ETH/USDC 0.05%プールの履歴を使い、OKX ETH無期限契約でのヘッジあり・なしを比較します。期間は約6・12・24時間で、元本、範囲、ヘッジ比率、費用を設定できます。USDTとUSDCを1対1で換算します。

最初の2ページは手動取得と5分間隔の取得に対応します。選択した根拠は各ページからJSONで出力できます。データはOKX、Ethereum dRPC、PublicNodeの公開APIから取得します。損益は模擬計算で、証拠金拘束と市場間の資産移動費用は計上しません。

## EVAAイベント検証

EVAA通知を選び、カードの「検証」を開きます。直近の完了区間も選べます。通知足の確定前後3・5・10分で、BNB ChainのUniswap v3 0.30%とPancakeSwap v3 0.01%のEVAA/USDTプールを比較します。同じEVAA数量で3ブロックの買い・売りを見積もり、プール手数料と価格影響を含めます。ガス代は含みません。スワップと流動性の追加・削除には取引ハッシュが付きます。取得できない過去の見積もりは欠損として表示し、結果をJSONで出力できます。

## 通知ルール

- **A · 現物出来高急増。** 直近1時間の売買代金が過去30日間の時間別中央値の2倍以上かつ95パーセンタイル以上。
- **E · 価格の急変動。** 直近1時間の現物価格の絶対変化率が過去30日間の95パーセンタイル以上。
- **OB · 建玉急増。** 4時間の建玉数量の増加率が10%以上かつ過去30日間の95パーセンタイル以上。
- **C · 資金調達率の異常。** 決済間隔で正規化した確定済み資金調達率が、正の場合は95パーセンタイル以上、負の場合は5パーセンタイル未満。

現物モデルにはAとE、完全モデルにはAまたはOBを含む2条件以上が必要です。再通知は銘柄・モデルごとに24時間の間隔を空けます。デリバティブデータが不足していても現物モデルは独立して動作します。

結果判定のしきい値は既定で20%です。10%、30%、50%にも変更できます。しきい値は通知ごとに保存され、実際に取引のある5分足が同方向に3本連続してしきい値に達して確定すると達成です。追跡中とデータ欠損は別々に表示されます。

## データとテスト

初回スキャンで直近32日間の現物データの補完を試みます。通知、設定、市場データのキャッシュ、ログは `data/alt_event_monitor/` に保存されます。通知はCSVに出力できます。過去のリプレイ一覧には、ローカルの調査アーカイブがある場合に事例が表示されます。

```powershell
.\.venv\Scripts\python.exe -m unittest tests.test_alt_event_monitor tests.test_alt_opportunities tests.test_evaa_replay -v
```
