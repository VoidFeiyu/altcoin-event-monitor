# アルトコイン機会分析

[简体中文](README.md) · [English](README.en.md) · 日本語 · [한국어](README.ko.md) · [Español](README.es.md)

Binance現物とAlphaの取引中銘柄を検索し、ウォッチリストまたは全銘柄を順次スキャンするWindowsツールです。通知後3・7・14日の結果、資金調達率、オンチェーン価格差、LPヘッジを調べられます。公開データのみを使用します。

## ブラウザ版レーダー

依存関係のインストール後、`start-monitor.bat` または `python -m klinebot.alpha_web --open` で[ローカルレーダー](http://127.0.0.1:8769/alpha)を開けます。

デスクトップ版は次のセクションのコマンドで起動できます。

## インストールと起動

ソースをダウンロードし、Tcl/Tk付きのPython 3.12をインストールしてください。プロジェクトのディレクトリでPowerShellを開き、次を実行します。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m klinebot.alt_monitor_app
```

言語メニューで日本語を選ぶと、設定が保存されます。「監視を開始」で定期スキャン、「今すぐスキャン」で単発スキャンを実行します。ウィンドウを閉じると停止します。

## 取引機会の分析

- **資金調達率・ベーシス**。空欄の場合、OKXのUSDT現物とリニア無期限契約の両方がある銘柄を順次スキャンします。銘柄はカンマ区切りで指定できます。
- **オンチェーン価格差**。選んだV3プールと対応するOKX現物の価格差を双方向で比較し、手数料と概算ガス代を差し引きます。
- **LPヘッジ検証**。選んだプールの約6・12・24時間を再現します。ヘッジ比率が0%ならプールデータのみで実行できます。ヘッジには対応するOKX USDT無期限契約が必要です。

最初の2ページは手動と5分間隔の取得に対応します。各ページで選択した根拠をJSONで出力できます。

## オンチェーン検証

レーダーの銘柄や通知から開くか、銘柄を選択するか、Ethereum・BNB Smart ChainのERC-20コントラクトを入力します。Uniswap v3とPancakeSwap v3のUSDT・USDC直接ペアを探します。通知足の前後3・5・10分または直近の完了区間を検証します。見積もりと取引ハッシュ付きイベントは別表示です。欠損を表示し、JSONで出力できます。

## 通知ルール

- **A · 現物出来高急増。** 直近1時間の売買代金が過去30日間の時間別中央値の2倍以上かつ95パーセンタイル以上。
- **E · 価格の急変動。** 直近1時間の現物価格の絶対変化率が過去30日間の95パーセンタイル以上。
- **OB · 建玉急増。** 4時間の建玉数量の増加率が10%以上かつ過去30日間の95パーセンタイル以上。
- **C · 資金調達率の異常。** 決済間隔で正規化した確定済み資金調達率が、正の場合は95パーセンタイル以上、負の場合は5パーセンタイル未満。

全銘柄レーダーは確定済み5分足でAとEを判定し、銘柄ごとに通知間隔を24時間空けます。OBとCを使った旧版の通知も確認できます。

結果判定のしきい値は既定で20%です。10%、30%、50%にも変更できます。しきい値は通知ごとに保存され、実際に取引のある5分足が同方向に3本連続してしきい値に達して確定すると達成です。追跡中とデータ欠損は別々に表示されます。

## データとテスト

全銘柄は1回につき最大24銘柄を処理し、約1分後に保存した位置から再開します。 初回スキャンで直近32日間の現物データの補完を試みます。通知、設定、市場データのキャッシュ、ログは `data/alt_event_monitor/` に保存されます。通知はCSVに出力できます。過去のリプレイ一覧には、ローカルの調査アーカイブがある場合に事例が表示されます。

```powershell
.\.venv\Scripts\python.exe -m unittest tests.test_alt_event_monitor tests.test_alt_opportunities tests.test_chain_replay -v
```
